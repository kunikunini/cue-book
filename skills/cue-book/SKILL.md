# Cue Book（制作用の見本帳）

言葉にしにくい動き・声・書体を、番号で受け渡すための見本帳です。利用者は見本を目で見て選び、番号で指示します。このスキルは、その番号から「何をどう動かすか」の仕様を取り出します。

| 巻 | 番号 | 中身 | 取り出せるもの |
|---|---|---|---|
| 01 | `AE-001`〜`AE-322` | After Effects に最初から入っているテキストアニメーションプリセット | 正式名・カテゴリ・動きの説明・単位／順番／変化する項目／緩急／長さ。曲線的な動きは参考の式つき |
| 02 | `MG-001`〜`MG-137` | モーショングラフィックスでよく使う動き | 名前・解説（仕組みと使いどころ）・見本を描いている Canvas 2D のコード一式 |
| 03 | `VT-001`〜`VT-130` | 音声合成で使うオーディオタグ | タグ・効果・例文・出どころ・使い方 |
| 04 | `FT-0001`〜`FT-2061` | 無料フォント（Google Fonts と Fontshare） | 名前・分類・太さ・読み込み用の `<link>`・CSS の指定・配布ページ。ライセンスの正確な条件は配布ページで確かめる |

道具は、このファイルと同じフォルダの `scripts/specimen.mjs` です（下の `<skill-dir>` は、この SKILL.md があるフォルダ）。Node.js 18 以上だけで動き、通信はしません（`pick` が自分のパソコンの中でだけ待ち受けます）。

```sh
node <skill-dir>/scripts/specimen.mjs <command>
```

| コマンド | 使いどころ |
|---|---|
| `get <番号...>` | 番号の仕様を出す。`AE-058`、`ae58`、`#MG-011`、見本帳のURLのどれでも通る。一度に12個まで |
| `search <言葉...>` | 言葉で探す。日本語でも英語でもよい。例：`search 文字 弾む`、`search wipe transition`。`--book ae\|mg\|vo\|ft` で巻を絞る、`--limit 20` で件数を増やす |
| `list` | 4巻の分類と件数。`--book ae` を付けると、その巻の全項目を1行ずつ |
| `table --book ae\|mg\|vo\|ft` | その巻の番号表（番号｜名前｜分類｜動き）。長いので、必要なときだけ |
| `pick` | 見本帳をブラウザで開き、利用者が選んで「AIに渡す」を押すまで待つ。選ばれた番号の仕様とメモを出して終わる |
| `info` | データの版、件数、見本帳の場所 |

共通：`--lang en` で英語、付けなければ日本語。

## 進め方

1. **番号を言われたら、まず `get`。** 利用者が番号で指示したら、その番号をそのまま `get` に渡し、出てきた仕様を読んでから作業します。名前だけ見て想像で作らないこと。
2. **貼られた内容も同じ扱い。** 見本帳の「選んだものをコピー」で作られた文章（「CUE BOOK（制作用の見本帳）から、次のN個を選びました」で始まる。表記が Cue Book のものや、旧名の「動きの見本帳から、…」も同じ）は、すでに仕様が入っています。そのまま使い、足りなければ `get` で引き直します。末尾の「メモ:」は利用者の指示です。
3. **選んでもらうなら `pick`。** 利用者が「見て選びたい」「どんなのがある？」と言ったら `pick` を実行します。場面が分かっていれば `--book` で巻を絞ります（文字の動き＝`ae`、図形や切り替え＝`mg`、声＝`vo`）。
   - 実行するとURLが表示され、ブラウザが開きます。利用者に「見本を選んで、右下の『AIに渡す』を押してください」と伝えます。
   - 最長15分待ちます（`--timeout 秒` で変更）。シェルの実行時間に上限がある環境では、バックグラウンドで走らせて終了を待つか、短い `--timeout` を付けます。
   - 終了コード 0：選ばれた順に、番号の仕様とメモが出ます。終了コード 4：時間切れで何も選ばれていません。代わりに選ばず、利用者に聞きます。
   - ブラウザが開かないときは、表示されたURLを利用者に渡します。それも無理なら、見本帳で「選んだものをコピー」して貼ってもらいます。
4. **選ばれたものだけを使う。** `pick` や貼り付けで届いた番号は確定です。勝手に足したり、別の番号に入れ替えたりしません。場面に合わないと思ったら、理由を言って聞きます。
5. **探すときは `search`。** 利用者が選ばず「いい感じのを選んで」と任せたとき、または見本帳を開けない環境のときに使います。名前ではなく、説明文で何が起きるかを読んで選びます。

## 巻ごとの使い方

### AE（After Effects のテキストプリセット）

- **After Effects で作る場合は、正式名のプリセットをそのまま当てます。** 場所は「エフェクト＆プリセット ＞ アニメーションプリセット ＞ Text ＞（カテゴリ）＞（正式名）」。これがいちばん正確です。プリセットのファイル（拡張子 `.ffx`）は、After Effects のアプリのフォルダにある `Presets` フォルダの中に入っています。
- **After Effects 以外（Web、Canvas、Remotion、動画生成AIへの指示など）で再現する場合は、`get` の仕様から作ります。** 「動かす単位」「順番」「変化する項目」「重なり方」「緩急」「長さ」をそのまま移します。参考の式が付いているものは、式の数値を変えずに使います。
- **仕様は近似です。** 名前とカテゴリは Adobe 公式ヘルプの一覧どおりですが、動きの仕様は After Effects 本体のプリセットファイルから取り出したものではなく、見本帳の作者がブラウザ上で再現したものです。本物と違う可能性があることを、利用者への報告に一言入れます。

### MG（モーショングラフィックスの動き）

- `get` で出るコードは、その見本を描いているものです。`draw(c, t, s)` と補助関数がそろっていて、そのまま動きます。横320×縦180、`t` は1周期の中の位置（0〜1）です。
- 別の技術（CSS、SVG、Remotion、After Effects のキーフレーム）へ移すときは、コードの中の秒数・遅れ・緩急・行きすぎ量・距離・角度を変えずに移します。変えてよいのは、表示する文字、色、ロゴや画像です。
- 解説文にある秒数や割合は目安です。尺に合わせるときは、比率を保って伸び縮みさせます。

### VT（オーディオタグ）

- タグは角かっこで書き、効かせたい言葉の直前に置きます。同じ調子は次のタグまで続きます。カンマで並べると重ねがけできます（例：`[whispering, fearful]`）。
- 対応は ElevenLabs の Eleven v4 / v4 Turbo / v3 です。タグは決まった一覧ではなく自由な言葉で書けますが、必ず効くとは限りません。効かなければ近い言葉に替えて生成し直します。
- 出どころが「Suno で使われる歌用タグ」のものは、歌を作るためのタグです。読み上げで効くとは限らないことを伝えます。
- 音声の生成は料金がかかります。利用者に頼まれていない生成はしません。

### FT（フォント）

- 読み込みは、出てきた `<link>` と `font-family` をそのまま使います。フォント名や太さを想像で書き換えないこと。使う太さだけに絞るのはかまいません。
- 書体のファイルは見本帳に入っていません。配布元（Google Fonts／Fontshare）から読み込むので、通信できない環境や自前で配信したい場合は、配布ページから入手するよう利用者に伝えます。
- ライセンスは「無料で商用利用可」が基本ですが、正確な条件は書体ごとの配布ページで確かめます。断定しないこと。
- 日本語が要るときは `--book ft` で「日本語: 対応」のものから選びます（`list --book ft` の先頭68個が日本語の書体。名前で探すなら `search mincho --book ft` など）。

## 守ること

- 番号が見本帳に無いときは、無いと伝えて `search` の候補を出します。番号を作らないこと。
- 一度にたくさん引かない。`list` と `search` は候補を探すため、`get` は実際に使う数個のため。`table` は利用者が番号表そのものを求めたときだけ。
- 仕事の最後に、使った番号と名前、どこに使ったか、何を変えたかを報告します。確かめられなかったことがあれば、それも書きます。

## うまくいかないとき

- **`pick` が「見本帳の場所が分かりません」（終了コード 3）**：見本帳のフォルダが手元にあれば `--site <フォルダ>`、公開されたURLが分かっていれば `--url <URL>` を付けます。どちらも無ければ、利用者に番号を聞くか、見本帳からコピーして貼ってもらいます。
- **Node.js が無い**：`data/catalog.json` は普通のJSONです。`items[]` の `id`・`name`・`nameJa`・`ja`・`en` で探し、`prompt.ja`（または `prompt.en`）が `get` の出力と同じ文章です。
